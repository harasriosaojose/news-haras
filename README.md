# News Haras — acompanhamento das obras

Revista eletrônica do Chacreamento Haras Rio São José para os clientes: andamento de cada obra, fotos de antes e depois, vídeos e canal de dúvidas e sugestões.

- HTML, CSS e JavaScript puro (sem build). Tudo o que aparece vem de `data/obras.json`.
- `scripts/gerar_obras_json.py`: textos, percentuais, pares de fotos e vídeos (editar aqui e rodar).
- `scripts/extrair_fotos_engenheiro.py`: extrai as fotos dos relatórios assinados do engenheiro para `assets/fotos/eng/`.
- `scripts/preparar_midia.py`: capa, fotos recortadas dos comunicados e vídeos em 720p.
- Dúvidas e sugestões ficam gravadas no Google Forms "News Haras: dúvidas e sugestões" (conta da administração).

Atualização mensal: trocar os números e as fotos no gerador, rodar os scripts, conferir no celular e publicar.
